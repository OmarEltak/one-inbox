## Workflow

1. Write blog into a seeder file → mark `[w]`.
2. Commit + push to `main` → GitHub Actions deploys (fallback: SSH manual pull).
3. Run seeder on prod: `sudo -u deploy bash -c "cd /var/www/ot1-pro.com && php artisan db:seed --class=AiSeoBlogSeeder --force"`.
4. `PostObserver` fires → IndexNow + Google Indexing pings.
5. Mark `[X]` once ping confirmed in `/var/www/ot1-pro.com/storage/logs/laravel.log`.
