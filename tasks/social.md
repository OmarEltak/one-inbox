## Sending checklist

- [ ] Use the **Cloud API** (approved templates) for lists > 50 numbers, not QR
- [ ] Match variant length to audience — regulars get the short one, cold list gets the longer one with social proof
- [ ] Send Thursday 9–10am Cairo, or Sunday 8pm — not Fridays
- [ ] Broadcast in batches of 30–50 if using QR, throttled 3–5 minutes apart
- [ ] Have someone monitoring the unified inbox for the first hour — the reply spike is when leads convert
- [ ] Track: sent, delivered, read, replied, and (the one that matters) booked / paid
